# Moss & Mood

A small hand-built website: *Design by Soul*.

All the files sit together in one folder (no sub-folders):

- `index.html` - the page itself (structure and words)
- `styles.css` - how everything looks
- `main.js` - how everything works
- all the other files (`.jpg`, `.png`, `.webp`) are the pictures

To change a picture, replace that file with a new one that has the same name.
Fonts (Dancing Script, Share Tech, DM Sans) load from Google Fonts.
